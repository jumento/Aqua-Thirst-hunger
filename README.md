# Aqua Thirst & Hunger

**The most complete hunger and thirst system for Hytale.** Balanced survival, custom foods, stamina buffs, poisoning, AFK detection, and seamless RPG leveling integration. 🍖💧

> Public release distributed on [CurseForge — Aqua Thirst & Hunger](https://www.curseforge.com/hytale/mods/aqua-thirst-hunger).
> Project ID `1450021` · License AGPLv3 · Game version: Early Access

## 💧 Aqua-Thirst & Hunger 🍗

Bring hunger and thirst mechanics into your Hytale experience. There are very few mods offering these mechanics right now, but none as complete and polished as ours. It's perfectly balanced to work as a secondary mechanic you don't need to babysit: it adds challenge to the game while also bringing real benefits along with it.

### 🍖 Real Survival

It gives real meaning to food and drinks in Hytale, and that same food can save your life:

- 💚 When wounded, you regenerate health over time by sacrificing hunger and thirst
- ✨ Gain extra saturation when eating the right foods
- 💨 Max out your thirst and get a stamina buff to travel long distances
- 🤢 New poisoning mechanic if you eat raw food, pushing you to discover new recipes

All of this makes the survival immersion in Hytale vastly more engaging.

### 🛠️ QoL like no other mod

- 🔊 Custom audio cues that act as fun notifications so you never die of hunger or thirst
- 💤 AFK detection: if the player is idle, hunger and thirst consumption pauses
- 🌱 New players join with extended saturation, giving them more time to gather food
- 🎒 Custom crafting recipes to carry water anywhere you go

### 🎮 RPG Integration: the experience expands

When you combine the mod with **MMO Skill Tree**, **RPG Leveling And Stats/Skills**, or **Endless Leveling**, its full potential unlocks:

- 🏹 **[RPG Leveling And Stats/Skills](https://www.curseforge.com/hytale/mods/rpg-leveling-and-stats)** → Earn XP boosts and let your level dynamically affect your food and water consumption, as well as your XP gains.
- 🗡️ **[Endless Leveling](https://www.curseforge.com/hytale/mods/endlessleveling)** → The higher your level, the more stable your hunger and thirst stats become. Gain extra XP when you keep your stats healthy… and lose XP when you neglect them.
- 🧙‍♂️ **[MMO Skill Tree](https://www.curseforge.com/hytale/mods/mmo-skill-tree)** → We use this powerful API to create a survival skill tree with rewards. It's incredible how much deeper the mod becomes once you have room to grow!
  - *Requires restarting the server twice (the first to initialize systems, the second to load the tree).*

### ⚙️ Main commands

Requires operator permissions (`/op self`).

- `/aquacheffconfig` → main configuration menu
  - Visual dashboard with presets (Easy / Normal / Hard)
  - Fully customizable settings
  - HUD in multiple positions
  - Built-in custom food editor
  - Life per hunger, thirst and hunger toggleable and customizable
- `/aquahunger set <0-100>` → set hunger level
- `/aquathirst set <0-100>` → set hydration level

### 🧬 Universal Compatibility

Designed to integrate with virtually any mod setup:

- Support for food mods and RPG systems
- Compatible with infinite water sources (AvidPixel's Infinite Water Supply)
- Automatic integration based on item rarity
- Scales with player progression through RPG mods (skills / leveling)

In the rare case of HUD conflicts, it's easily solved using **AutoMultiHUD** or disabling **MultipleHUD** depending on the case. This is a known Hytale issue, not caused by our mod, but we'll gladly help you fix it in the comments.

### 📖 Manifest

What started as a fork of **Hunger Core** ended up becoming one of the best survival mods for Hytale. Even though the foundation was solid, we rewrote the entire codebase to lay the groundwork for much bigger updates. Incredible plans are coming for this mod.

Eternal credit to **@Aex12** for the starting point — and to all of you for keeping the project alive.

This is only the beginning.

## Building from source

Requires Java 25 and access to the Hytale Server JAR.

1. Drop the Hytale Server JAR into `libs/`. It is a `compileOnly` dependency and is intentionally **not** committed (proprietary).
2. Build:
   ```bash
   ./gradlew jar
   ```
3. The output JAR appears under `build/libs/`. Drop it into your server's `mods/` directory.

### Project layout

```
src/main/java/mx/jume/
  aquahud/                  HUD bridge + multi-HUD container
  aquahunger/
    AquaThirstHunger.java   Plugin entry point
    assets/                 FoodValue asset registration
    commands/               /aquahunger, /aquathirst, /aquacheff, ...
    compat/                 RPGLeveling, EndlessLeveling, MMOSkillTree bridges
    components/             HungerComponent, ThirstComponent (ECS)
    config/                 Config files + migration manager
    events/                 PlayerReady, PlayerDisconnect, GameMode watcher
    interactions/           FeedInteraction, StartFeedingInteraction
    systems/                StarveSystem, ThirstSystem, HungerLifeSystem
    ui/                     HUDs and configuration pages
src/main/resources/
  Common/UI/Custom/Hungry/  HUD .ui definitions
  Server/                   Items, interactions, entity effects, languages
  mmo/                      Custom skills, skill tree, XP maps
mods/Aqua-Thirst-hunger/
  ExternalFoodsDefaultConfig.json   bundled defaults (250+ external foods)
```

### Configuration files

All configs live in `mods/Aqua-Thirst-hunger/` and are generated on first run:

| File | Purpose |
|---|---|
| `HungerConfig.json` | Initial level, max, depletion rates, starvation damage, life-per-hunger pulse, satiation thresholds. |
| `ThirstConfig.json` | Max thirst, depletion, dehydration damage, stamina boost threshold, satiation thresholds. |
| `FoodValuesConfig.json` | Per-tier hunger restoration / saturation, plus per-item overrides. |
| `ThirstFoodValuesConfig.json` | Per-tier thirst restoration, fruit multiplier, per-item overrides (Canteen, BasicBottle, etc.). |
| `ExternalFoodsDefaultConfig.json` | Bundled defaults for 250+ modded foods. **Do not edit** — overwritten on each launch. |
| `ExternalFoodsConfig.json` | Your personal overrides for external foods. **Never touched** by the mod. |
